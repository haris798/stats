# Stats.ku (ScreenTime.ku) 📱

Aplikasi Pelacak Screen Time Offline-First Berbasis Android & Web UI dengan Arsitektur **React + Vite + Capacitor + Native Kotlin Layer + Room SQLite + WorkManager + Supabase**.

---

## 🏗️ Arsitektur Aplikasi

```
                 ┌───────────────────┐
                 │ React + Vite + TS │
                 │ Web UI Dashboard  │
                 └─────────┬─────────┘
                           │
                      Capacitor
                           │
                 ┌─────────▼─────────┐
                 │ Native Kotlin     │
                 ├───────────────────┤
                 │ UsageStatsManager │
                 │ Room SQLite DB    │
                 │ WorkManager       │
                 │ DataStore         │
                 └─────────┬─────────┘
                           │
                       Sync Queue
                           │
                           ▼
                    ┌──────────────┐
                    │ Supabase REST│
                    └──────────────┘
```

1. **Local Source of Truth**: Room SQLite Database pada Android (dan LocalStorage / Mock Provider pada Web Browser fallback).
2. **Remote Storage**: Supabase PostgreSQL REST API dengan Idempotent `UPSERT`.
3. **Offline-First**: Aplikasi berfungsi 100% tanpa jaringan internet. Data tersimpan lokal di Room SQLite dan secara otomatis disinkronkan oleh `WorkManager` ketika koneksi internet aktif.

---

## ⚙️ Ringkasan Fitur Utama

- 📊 **Dashboard Screen Time**: Total durasi harian, perbandingan vs kemarin, statistik 7 hari, top 5 aplikasi, dan jumlah pemakaian harian.
- 📅 **Riwayat Penggunaan**: Melihat statistik harian mundur hingga 1 tahun dilengkapi Empty State interaktif.
- 📱 **Penggunaan & Detail Aplikasi**: Memantau grafik 7 hari, durasi harian, kategori, dan frekuensi buka per aplikasi.
- 🔄 **Sinkronisasi Otomatis & Manual**: Tombol **Sync Now** dengan pembaruan status real-time (*Collecting -> Saving Room -> Syncing Supabase -> Complete*).
- 🌓 **Tema Terang & Gelap**: Tombol sakelar tema di header navigasi dengan penyimpanan preferensi di LocalStorage.
- 💾 **Retensi Data Lokal**: Pengaturan batas retensi data lokal (30 Hari, 90 Hari, 1 Tahun, atau Semua Data).
- 🤖 **Build Otomatis APK**: Integrasi GitHub Actions (`.github/workflows/build-apk.yml`).

## 🗄️ Script Build Database Supabase SQL

File skema SQL telah disediakan di file `supabase_schema.sql` atau dapat disalin langsung dari blok di bawah ini untuk dijalankan di **SQL Editor** pada [Supabase Dashboard](https://supabase.com):

```sql
-- 1. Tabel Utama Screen Time Usage
create table if not exists public.screen_time_usage (
    id bigint generated by default as identity primary key,
    device_id text not null,
    usage_date date not null,
    package_name text not null,
    app_name text,
    total_time_foreground bigint not null default 0,
    usage_minutes integer not null default 0,
    open_count integer default 1,
    first_used_at timestamptz,
    last_used_at timestamptz,
    created_at timestamptz not null default now(),
    updated_at timestamptz not null default now(),
    unique(device_id, usage_date, package_name)
);

-- 2. Indeks Performa Query
create index if not exists idx_screen_time_device_date
on public.screen_time_usage(device_id, usage_date);

create index if not exists idx_screen_time_usage_date
on public.screen_time_usage(usage_date);

-- 3. Aktifkan Row Level Security (RLS)
alter table public.screen_time_usage enable row level security;

-- 4. Kebijakan RLS (Insert, Select, Update)
create policy "Allow anon insert/upsert screen_time_usage"
on public.screen_time_usage for insert
with check (true);

create policy "Allow anon select screen_time_usage"
on public.screen_time_usage for select
using (true);

create policy "Allow anon update screen_time_usage"
on public.screen_time_usage for update
using (true);
```

### Konfigurasi Kunci Akses Supabase
Masukkan kredensial Supabase Anda pada file `.env` atau langsung melalui halaman **Pengaturan & Izin** di UI aplikasi:

```env
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_ANON_KEY="your-supabase-anon-key"
```

> 🚨 **PENTING**: Gunakan **hanya** `ANON_KEY` untuk aplikasi client. Jangan pernah memasukkan `SERVICE_ROLE_KEY`.

## 🚀 Panduan Jalankan & Build

### 1. Instalasi Dependencies

```bash
npm install
```

### 2. Mode Pengembangan Web Browser (`npm run dev`)

```bash
npm run dev
```

### 3. Build Web Bundle

```bash
npm run build
```

### 4. Sinkronisasi Capacitor Android

```bash
npx cap sync android
```

### 5. Build APK Android Debug

```bash
cd android
./gradlew assembleDebug
```
Hasil file APK berada di lokasi: `android/app/build/outputs/apk/debug/app-debug.apk`.

## 🔐 Panduan Izin Usage Access di Android

Supaya aplikasi dapat membaca statistik penggunaan perangkat secara akurat:

1. Buka **Pengaturan / Settings** di HP Android Anda.
2. Pilih **Aplikasi / Apps** → **Akses Aplikasi Khusus / Special app access**.
3. Pilih **Akses Penggunaan / Usage access**.
4. Cari dan pilih **Stats.ku** / **ScreenTime.ku**.
5. Aktifkan **Izinkan Pelacakan Penggunaan / Allow usage tracking**.
