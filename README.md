# Stats.ku (ScreenTime.ku) 📱

Aplikasi pelacak Screen Time offline-first berbasis Android & Web UI dengan arsitektur **React + Vite + Capacitor + Native Kotlin Layer + Room SQLite + WorkManager + Supabase**.

---

## 🏗️ Arsitektur Aplikasi

```
                 ┌───────────────────┐
                 │ React + Vite + TS │
                 │ Web UI Dashboard  │
                 └─────────┬─────────┘
                           │
                      Capacitor
                           │
                 ┌─────────▼─────────┐
                 │ Native Kotlin     │
                 ├───────────────────┤
                 │ UsageStatsManager │
                 │ Room SQLite DB    │
                 │ WorkManager       │
                 │ DataStore         │
                 └─────────┬─────────┘
                           │
                       Sync Queue
                           │
                           ▼
                    ┌──────────────┐
                    │ Supabase REST│
                    └──────────────┘
```

1. **Local Source of Truth**: Room SQLite Database pada Android (dan LocalStorage pada Web Dev fallback).
2. **Remote Storage**: Supabase PostgreSQL REST API dengan Idempotent `UPSERT`.
3. **Offline-First**: Aplikasi berfungsi 100% tanpa internet. Jika internet mati, data tersimpan di Room dengan status `PENDING` dan secara otomatis disinkronkan oleh `WorkManager` ketika online.

## 🚀 Panduan Jalankan & Build

### 1. Instalasi Dependencies

```bash
npm install
```

### 2. Mode Pengembangan Web (`npm run dev`)

```bash
npm run dev
```
Mode browser menggunakan `MockUsageStatsProvider` untuk menyimulasikan data `UsageStatsManager` dan Room SQLite sehingga UI dapat dikembangkan dan diuji secara penuh di browser tanpa device Android.

### 3. Build Web Bundle

```bash
npm run build
```

### 4. Sinkronisasi Capacitor Android

```bash
npx cap sync android
```

Membuka Android Studio (opsional):
```bash
npx cap open android
```

### 5. Build APK Android

```bash
cd android
./gradlew assembleDebug
```
Output APK berada di:
`android/app/build/outputs/apk/debug/app-debug.apk`

## 🗄️ Konfigurasi Supabase Backend

1. **Buat Project Baru** di [Supabase Dashboard](https://supabase.com).
2. Buka **SQL Editor** pada Supabase Dashboard dan jalankan script SQL berikut:

```sql
create table if not exists public.screen_time_usage (
    id bigint generated by default as identity primary key,

    device_id text not null,

    usage_date date not null,

    package_name text not null,

    app_name text,

    total_time_foreground bigint not null default 0,

    usage_minutes integer not null default 0,

    open_count integer default 1,

    first_used_at timestamptz,

    last_used_at timestamptz,

    created_at timestamptz not null default now(),

    updated_at timestamptz not null default now(),

    unique(device_id, usage_date, package_name)
);

create index if not exists idx_screen_time_device_date
on public.screen_time_usage(device_id, usage_date);

create index if not exists idx_screen_time_usage_date
on public.screen_time_usage(usage_date);

-- Enable Row Level Security (RLS)
alter table public.screen_time_usage enable row level security;

-- Policies for anon access
create policy "Allow anon insert/upsert screen_time_usage"
on public.screen_time_usage for insert
with check (true);

create policy "Allow anon select screen_time_usage"
on public.screen_time_usage for select
using (true);

create policy "Allow anon update screen_time_usage"
on public.screen_time_usage for update
using (true);
```

3. Masukkan `SUPABASE_URL` dan `SUPABASE_ANON_KEY` pada file `.env` atau melalui menu **Settings & Sync** di dalam aplikasi:

```env
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_ANON_KEY="your-supabase-anon-key"
```

> 🚨 **PENTING**: Jangan pernah memasukkan `SUPABASE_SERVICE_ROLE_KEY` ke dalam aplikasi Android/Web UI client. Gunakan **hanya** `ANON_KEY`.

## 🔐 Izin Usage Access pada Android

Supaya aplikasi dapat membaca statistik penggunaan screen time di perangkat Android nyata:

1. Buka **Settings** pada HP Android Anda.
2. Buka **Apps** / **Aplikasi**.
3. Pilih **Special app access** (Akses aplikasi khusus) → **Usage access** (Akses penggunaan).
4. Cari **ScreenTime.ku** / **Stats.ku**.
5. Aktifkan **Allow usage tracking** (Izinkan pelacakan penggunaan).
6. Kembali ke aplikasi Stats.ku, aplikasi akan otomatis memuat data penggunaan screen time secara langsung.

## ⚙️ Fitur Utama

- 📊 **Dashboard Screen Time**: Total durasi, perbandingan vs kemarin, statistik 7 hari, top 5 apps, dan jumlah aplikasi dibuka.
- 📅 **Riwayat Penggunaan**: Melihat statistik harian mundur hingga 1 tahun.
- 📱 **Detail Aplikasi**: Memantau grafik 7 hari, durasi harian, dan jumlah dibuka per aplikasi.
- 🔄 **Sinkronisasi Otomatis & Manual**: Tombol **Sync Now** dengan feedback progress transparan (Collecting -> Saving Room -> Syncing Supabase -> Complete).
- 💾 **Local Retention**: Pengaturan batas retensi data lokal (30 hari, 90 hari, 1 tahun, atau semua data).
- 🤖 **GitHub Actions**: Automated APK build workflow (`.github/workflows/build-apk.yml`).
